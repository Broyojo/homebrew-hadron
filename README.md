# Homebrew tap for Hadron

[Hadron](https://github.com/Broyojo/hadron) plays Windows games from the Steam library of the
native Mac Steam client, on Apple Silicon Macs.

```sh
brew install --cask broyojo/hadron/hadron
```

The cask is written by Hadron's release script from `packaging/homebrew/hadron.rb` in the main
repository; changes belong there.
